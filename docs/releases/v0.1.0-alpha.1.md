Skeiner's first public alpha turns an OpenAPI service into two MCP tools. Agents can discover authorized operations with `search`, write JavaScript to combine calls with `execute`, and rerun a saved investigation with `skeiner run`.

The release includes macOS and Linux binaries for Intel/AMD 64-bit and ARM64. Download the archive for your platform, verify it against `SHA256SUMS`, and extract it. From the extracted directory, run `python3 examples/rates/quickstart.py` for an offline MCP example.

The reproducible inventory benchmark reads six pages to find eight reviewed PRs with failed required checks. Running the saved program returns 366 bytes to the client, compared with 18,277 bytes when the client receives each page. Both paths make six upstream reads. The repository includes the fixture, answer checks, and runtime measurements.
