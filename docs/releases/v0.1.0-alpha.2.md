Skeiner can now rerun one JavaScript file with changing JSON inputs. Pass a file with `skeiner run --input-file` or supply `input` to MCP `execute`. The program reads `api.input`. A paginated investigation can reuse the same source when resuming from a checkpoint.

`skeiner eval --program` verifies a saved investigation against owner-defined cases, using the HTTP records actually retrieved to grade its citations. The distribution includes a three-case log investigation you can run offline.

MCP discovery now reports the exact enum values declared on scalar response fields. On a new museum-loans API, both GPT-4.1 mini authors initially compared wrongly capitalized status values and returned zero matches. With those values visible in discovery, two fresh mini authors and one GPT-4.1 author each wrote a program that passed all three snapshots. The study includes the verification cost and a direct Python baseline.

For repeated CLI runs on Linux or macOS, `--runtime-cache DIR` reuses compiled QuickJS in a private local directory. Across 20 fresh processes doing three loopback reads, median time fell from 230 ms to 64 ms with a populated cache. The median first run with an empty cache took 257 ms.
